保存在本机

保存工作站面板中的编辑配置。要保存拖动后的布局，先在场景面板点击“采用画面摆放”。

本机列表保存在当前浏览器；导出的文件可备份和分享。

导入已有场景

支持 RoboStudio 导出的 .robostudio.json / .json 场景文件（小于 14 KB），也兼容旧版纯配置 JSON。这里载入桌面配置；XML / MJCF、URDF、STL、OBJ 模型和运行记录不适用。

文件中保存了什么？

机械臂类型、任务、算法设置、物体与障碍的位置 / 尺寸 / 旋转，以及质量、摩擦、重力和接收区。文件单位为 m、rad、kg。载入后物体从桌面开始，时间归零；速度、空中姿态和任务进度属于运行记录。
