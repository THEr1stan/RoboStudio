# AlgorithmSpec template

This directory holds a non-executable, synthetic example for testing the schema. It is not an actual paper or a verified equation. P0 must define and freeze the formal schema and validation rules before real use.

Suggested minimal fields: schema_version, source (paper hash, title, section), method (family, equations, inputs/outputs, parameters, assumptions, claims), review status and provenance tags. See `docs/PROJECT_PROPOSAL.md` section 5.2.
