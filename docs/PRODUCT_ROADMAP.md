# 产品方向与当前边界

当前版本是 **v0.8.0 Windows 桌面仿真工作环境**，实际能力以 README、使用指南和当前交付记录为准。
原始 PROJECT_PROPOSAL 是长期技术方向，不是所有功能已实现的承诺，也不是自动实施全部内容的指令。

## 已实现的闭环

两种机构在可编辑桌面场景中持续搬运、分拣与码垛；用户能拖动物体和末端、施加外力，
查看真实算法过程、物理接触和失败原因，在匹配条件下对照算法并保存数据。
App 提供工业工位、本机命名场景、JSON 交换、独立窗口与离线运行环境。

## 下一项最小任务

在第二台干净 Windows 机器从 GitHub Release 下载并运行，验证缺少开发环境时的启动、
第一次抓取、场景导入导出和退出；记录系统版本、依赖和实际失败情况，再决定是否制作安装器。
这项验证尚未完成，发布当前便携包不等于已覆盖所有电脑。

## 待单独立项的方向

| 方向 | 所需验收 |
|---|---|
| 更多机器人 / URDF | 资产许可、关节与执行器映射、零位和单位、运动学与动力学测试 |
| 更丰富工业现场 | 动态来料、夹具和多工位任务的真实物理与失败恢复 |
| Paper-to-Simulation | 来源页码、人工规格审核、资源受限的隔离候选执行、公平基线对照 |
| 跨平台桌面与安装器 | 独立打包、图形兼容、升级迁移、签名与卸载 |
| ROS / 真机 | 通信合同、设备安全、时序和独立硬件验收；当前不包含 |

扩展以可完成的功能和可复现数据为准，不以算法名称或模型数量为准。
论文实现验证、迁移到本项目的实验、复现论文原始实验必须分别标注。
