# RoboStudio AI

**v0.8.0 · 桌面工作环境。** 编辑桌面场景，让六轴机械臂或三轴龙门通过虚拟相机
定位物体，执行接触抓取、避障搬运、分拣和堆叠，并查看真实轨迹、接触力和算法对照。

首次打开请按 [入门路线](QUICK_START.md) 操作；场景文件说明见 [自定义场景](SCENES.md)。

## 打开与体验

双击 `RoboStudio.exe` 或项目根目录 `Start-RoboStudio.cmd`，进入独立桌面 App。
菜单“工作区”保留算法实验室、论文规格和基础验证入口。网页工作台仍可作为开发入口。
也可以运行 `.venv/Scripts/python.exe -m robostudio workbench --open`。
刷新后自动执行并持续维护搬运目标；移走已放好的物体，会重新观察并搬运。系统减少动态效果设置会关闭自动运行。
`/?demo=0` 可直接进入静止场景。不要直接打开 HTML 文件。

- 顶部选择 R6 Compact / XYZ Gantry，以及单物体搬运、颜色分拣、积木堆叠。
- 顶部“场景库 → 工业工位”提供零件上下料、来料分拣、成品码垛、隔板避障转运。
  选择卡片查看布局与作业流程，点击“载入并运行”直接执行；“载入编辑”可先调整尺寸和摆放。
  预览右侧“下载此场景 JSON”获得所选工位的可导入文件，无需编写 JSON。
- 场景库还提供基础示例、本机命名保存和 JSON 导入预览。
  在侧栏编辑三维尺寸、质量、摩擦与障碍，或拖动后“采用画面摆放”，再保存 / 导出。
  本机列表属于当前 App；旧浏览器列表通过 JSON 导出 / 导入迁移；场景载入时回到桌面初始布局，不恢复运行进度。
- 连续施力采用最新目标合并与物理步交替调度，画面按帧合并重绘；算法详情仅在变化时更新。
- 顶部算法选择立即提交，不必应用或播放；控制器立即切换，逆解/规划/时标用于下一段运动。
- 点击颜色按钮或画面中的积木，直接选为抓取目标；单物体任务跟随选择，分拣优先处理选中物体，堆叠保持底层顺序。
  若正在夹持其他物体，会先完成其放置，再执行新目标。各物体使用独立接收位置，避免重叠。
- 按住积木直接移动；保持按住时滚轮或 Shift 拖动可升降，松手恢复重力和接触，再从新位置抓取。
  移动经过几何检查，遇到障碍停住，抬高后可越过。右键旋转、空格暂停、Esc 松手。
- 积木拖动受阻时，实际阻挡部件显示橙色轮廓，并标明障碍 / 积木颜色 / 机械臂夹指 / 桌面及当前间隙。
  滚轮会从实际停住的位置抬起；绕开或松手后提示消失，不增加操作按钮。
- 连杆保留有界弹簧外力；末端使用实际逆解和碰撞路径。
- “转为自由操控”挂起任务，物理环境继续运行；“交给机械臂”恢复持续目标。
- 连杆施力叠加到当前任务，控制器继续运行，松手只清除外力，保留阶段、夹持和已完成进度。
  真实抓取失败才进入恢复；手动接管后贴桌时仍可经检查退让。Esc、切出窗口均清除外力。
- 场景面板编辑 1–3 个不同颜色的长方体/圆柱、尺寸、质量、摩擦、旋转、重力和接收区；
  可添加最多 4 个障碍物，随机布置，导入/导出有界 JSON 场景。结构/物理参数修改重建场景；直接拖动不重置。
- 鼠标旋转/缩放三维画面，拖动末端（Shift 升降）后由逆解、规划与力矩控制执行；
  六轴支持姿态输入，龙门保持固定工具姿态。支持关节操作、开合夹爪和示教回放。
- 物理暂停、2 ms 单步、速度控制；运行时可对物体施加有限持续外力，动作写入记录。
- 自动流程：图像观测 → 抓取候选 → 碰撞路径 → 所选时标轨迹 → 力矩控制 → 双指接触检查
  → 搬运 → 释放 → 移开相机遮挡 → 观察结果；失败会重新观察并有限重试。
- 感知页显示射线彩色图、深度图、检测框、深度噪声/缺失/延迟、接触力与跟踪误差。
- 运算面板显示实际求解使用的 q、Δq、残差、Jacobian、FK、阻尼、最小奇异值与抓取候选。
- 同场景比较 DLS/自适应 DLS/SVD/JT、RRT/RRT-Connect/PRM/直线检查、三种时标、计算力矩/PD、相机/真值。
  每个结果来自完整的物理运行，支持回放、CSV 指标和原始 JSON。
- 运行记录包含成功与失败；可以重新执行相同配置和操作并严格验证所有保存的数据。

自主抓取通过 MuJoCo 积分、摩擦接触与执行器完成，无附着或预置动画。用户按住积木时是明确的手动位置约束，
会直接修改该物体状态，不代表机械臂施力或自主抓取；松手清零物体速度，恢复动力学。
网页按请求推进有界物理步批次；暂停或关闭页面时不推进，仿真倍速不是硬实时承诺。
连续环境保存最近约 40 秒画面和全部输入，可从初始状态严格复算。
当前版本验证与物理对照见 [交付记录](releases/DESKTOP_V080.md)。

## 算法实验室

在 App 菜单“工作区”打开算法实验室。网页开发入口为 `/?page=algorithms&demo=0`。
顶部按用途分组，先运行算法，再用播放、单步、滑块检查过程；“本组对照”重新计算同条件案例。

| 类别 | 实现 | 可以观察什么 |
|---|---|---|
| 逆运动学 | DLS、自适应 DLS、SVD 伪逆、雅可比转置 | 实际迭代姿态、残差、q/Δq、Jacobian、阻尼、奇异值 |
| 路径规划 | RRT、RRT-Connect、PRM + Dijkstra、直线检查 | 搜索尝试、两棵树、拒绝点、关节投影、最终路径 |
| 轨迹时标 | 五次、三次多项式、梯形速度 | 同一路径和时长下的位置、速度、加速度 |
| 关节控制 | 计算力矩、PD + 偏置补偿 | 2 ms MuJoCo 物理执行、实际跟踪误差、力矩 |

“用于抓取任务”将算法和实验场景应用到工作站；点击“开始任务”执行真实抓取流程。
展开“查看当前任务的算法记录”可选择任务阶段，读取该次任务保存的逆解/规划过程。
算法预览使用独立模型，不修改现场。逆解迭代与参考轨迹不是物理执行；控制实验才积分动力学。
导出的 JSON 包含配置、模型/源码/任务哈希、种子、版本、完整计算记录与复算请求。
网页支持“复算验证”，或运行：

```powershell
.venv/Scripts/python.exe scripts/replay_lab.py --record path/to/lab_export.json
.venv/Scripts/python.exe scripts/validation/verify_algorithms.py --output artifacts/algorithms-validation
```

规划有 450 次采样和 12,000 次构型检查上限；0.028 SI 的离散检查不是连续碰撞保证。
三维搜索线是关节构型对应的 TCP 连线，红点是失败构型的 TCP，不是接触点。
PRM 为逐次建图实现，尚未跨查询复用；自适应 DLS 为明确公开的项目内阻尼策略。
每种算法均在当前源代码与回归测试中保留，不需要下载早期版本。

## 已实现范围

模型是项目原创的理想化机构。WebGL 显示引擎几何与位姿；关节外壳和龙门支架是装饰。
实际夹指、掌部、桌面、地面、物体和障碍物参与接触；机械相邻连杆排除自碰撞，检查较远连杆。
龙门轨道/滑块的外壳不参与接触。默认物体小于夹爪开口，场景参数有明确边界。

相机为 **128×112、10 Hz 的射线 RGB/深度传感器**，颜色是物体材质平面色。
识别使用颜色阈值、连通域、标定反投影和 XY 主方向分析；支持已知三种颜色，无训练模型。
相机模式用观测估计抓取位置，碰撞规划仍使用已知场景几何，真值仅用于评估或显式基线。
不是照片级渲染、未知物体通用视觉或仅靠相机重建障碍地图。

RRT 使用有界随机搜索与离散边检查；携带物体按近似包络检查，不保证任意场景可解。
自动抓取为顶向平行夹持；尚无任意 URDF 导入、SCARA、传送带、柔体、实机标定或 ROS 连接。

App 的“工作区”菜单保留论文规格工作流和基础验证；开发路径分别为 `/workcell`、`/advanced`。
论文入口只提供规格审核和受限候选模板导出，不会自动解析任意论文或执行生成代码。

## 环境

Python 3.11+；本地验收使用 Windows CPython 3.15 与 3.12。现有固定依赖为
MuJoCo Core 4.0.1 和 NumPy；桌面壳新增微软 WebView2 SDK；没有 CDN、在线字体或外部机器人资产。
产品不需要 Node；浏览器需支持 WebGL 2。可选 Playwright 仅用于验收。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.lock
.venv/Scripts/python.exe -m pip install --no-build-isolation -e ".[physics]"
.venv/Scripts/python.exe -m robostudio workbench --open
```

基础包无第三方运行依赖；没有 physics 时，/advanced 仍可作几何预览和工程测试。
没有将当前验证扩展到 Linux/macOS 或实机。

## 数据与验证

新记录位于 `artifacts/studio_<24位ID>/run.json`。物理与控制周期 2 ms，画面/轨迹采样 40 ms；
相机计算周期 100 ms，记录每秒的图像及任务观测关键帧。统计量按每个物理步累计。
保存状态、参考、命令、场景几何、全场景 qpos/qvel/ctrl、算法轨迹、计划、图像、操作事件、
显式映射、配置/任务/模型/源码哈希、随机种子和版本。保存帧不是全部 500 Hz 原始观测。

```powershell
.venv/Scripts/python.exe -m ruff check src tests scripts
.venv/Scripts/python.exe -m ruff format --check src tests scripts
.venv/Scripts/python.exe -m mypy src/robostudio
.venv/Scripts/python.exe -m pytest -q
node --test tests/web/kinematics.test.mjs
node tests/browser/studio.cjs
.venv/Scripts/python.exe scripts/validation/verify_studio.py --replay
.venv/Scripts/python.exe -m robostudio experiment replay studio_<ID>
```

新浏览器验收可用 STUDIO_URL 指定服务。旧浏览器验收的 WORKBENCH_URL 分别指向 /workcell、/advanced。
源码或环境变化时，严格复算应拒绝声称一致；旧记录仍可浏览和导出。

## 工程入口

| 文件 | 职责 |
| --- | --- |
| simulation/scene.py | 场景验证、模型适配、引擎几何与接触读数 |
| simulation/sensor.py | 射线 RGB/深度、图像处理与反投影 |
| simulation/planning.py | 双向 RRT、相同条件的直线基线、独立碰撞探针 |
| simulation/runtime.py | 在线物理、抓取任务、观测检查、重试、手动控制与数据 |
| simulation/api.py | 本地隔离会话、记录、实验与严格重算 |
| ui/studio/* | 浅色工作站与原生 WebGL 三维显示 |
| cell_ik.py、cell_plugins.py、core/ | 共享求解器、受校验清单与无引擎合同 |
| scripts/validation/verify_studio.py | 两种机构的固定 30 个场景，包含失败和复算 |

当前版本的实际验证与已知边界见 [v0.8.0 交付记录](releases/DESKTOP_V080.md)。
