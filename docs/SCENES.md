# 自定义与分享场景

不需要先找一份 JSON，也不需要手写代码。**先在 App 中搭场景，再导出文件** 是最直接的方式。

## 从工业工位开始

1. 场景库选择工位，点击 **载入编辑**。
2. 在场景面板修改机器人、任务、物体形状、尺寸、位置、质量、摩擦、障碍和接收区。
3. 如需直接摆放，按住三维画面里的物体拖动，滚轮升降；完成后点 **采用画面摆放**。
4. 场景库填写名称，点 **保存到本机**，或点 **导出 JSON 文件**。
5. 运行任务，检查可达性、碰撞和放置结果。能导入的配置不一定是可成功完成的任务。

本机命名场景最多 12 个，属于当前 App 的资料目录。JSON 文件用于备份、版本管理和分享。
内置工位卡片的 **下载此场景 JSON** 和 **下载可修改的示例 JSON** 也能直接生成文件。

## 从仓库取得可用文件

打开 [工业场景示例目录](../examples/scenes/README.md)，下载其中任意 `.robostudio.json`。
在 GitHub 文件页面选择 **Download raw file**；不要把网页另存为 JSON。
App 场景库选择该文件，查看验证预览后载入。载入会重置物理时间及当前任务进度。

## 支持哪些格式

| 文件 | 能否作为场景导入 | 用途 |
|---|---|---|
| RoboStudio 导出的 `.robostudio.json` / `.json` | 可以 | 初始机器人、任务、算法、物体和障碍配置 |
| 旧版 RoboStudio 纯配置 JSON | 兼容校验通过的配置 | 同上 |
| 运行记录 `run.json` | 不可以 | 从记录区查看与严格复算 |
| URDF、MJCF/XML、STL、OBJ | 不可以 | 不是本版本支持的场景文件 |
| 任意其他 JSON | 不一定 | JSON 是通用文件格式，不代表字段符合场景合同 |

格式标识是 `robostudio-scene-v1`，文件小于 14 KB。配置由后端再次验证；错误版本、
错误单位、越界参数或无效字段会被拒绝，验证预览本身不会替换现场。

## 文件中保存什么

导出文件包含 `schema`、`name`、`units` 和完整 `config`。
请直接修改示例中的完整 `config`，不要把下面的字段说明当成可直接导入的文件。

| 字段约定 | 含义 |
|---|---|
| `schema` | 固定为 `robostudio-scene-v1` |
| `units` | 长度 m、角度 rad、质量 kg |
| `config` | 机器人、任务、算法、种子、物体、障碍、重力及接收区 |
| 物体 `size` | 三维半尺寸，单位米；圆柱取 X 半径与 Z 半高 |

界面使用 mm、度和 g 显示，文件使用 SI 单位。例如 40 mm 宽的箱体，对应 X 半尺寸 `0.020` m。
当前支持 1–3 个不同颜色的箱体 / 圆柱、最多 4 个障碍，以及 R6 和 XYZ 两种机构。
具体数值边界由场景校验器控制；界面输入比手工猜测字段更稳妥。

场景描述初始布局：物体从桌面开始，不恢复当前速度、空中姿态、夹持状态或执行进度。
需要保存运行过程，请用 **保存当前运行**。不要把 Data/WebView 个人资料整个上传到仓库。

实现入口：[场景文件合同](../src/robostudio/simulation/documents.py)、
[物理场景校验](../src/robostudio/simulation/scene.py)。
