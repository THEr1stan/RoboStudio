# 第一次使用 RoboStudio

本指南对应 **v0.8.0 / Windows x64**。目标是完成一次接触抓取，改变现场，再留下可查看的数据。
无需真实机械臂、Python 或编程经验。

## 1. 下载并打开 App

1. 打开 [最新版本下载](https://github.com/THEr1stan/RoboStudio/releases/latest)。
2. 在 **Assets** 下载 `RoboStudio-0.8.0-win-x64.zip`。GitHub 自动提供的 **Source code** 是源码，不是可直接启动的 App。
3. 解压整个文件夹到你有写入权限的位置，例如“文档”下。不要在压缩包内运行，也不要只复制 exe。
4. 双击 `RoboStudio.exe`，等待机械臂和桌面出现。首次启动会创建旁边的 `Data` 文件夹。

系统要求：Windows 10/11 64 位、.NET Framework 4.8、WebView2 Evergreen Runtime，以及支持 WebGL 2 的显卡环境。
缺少组件时按启动提示安装官方运行环境，详见 [故障排查](TROUBLESHOOTING.md)。便携包已包含 Python、NumPy 和 MuJoCo。
程序尚未数字签名；可以先用 `Get-FileHash` 对照 Release 的 `SHA256SUMS.txt` 核对下载文件。

## 2. 完成第一项工业任务

1. 顶部打开 **场景库 → 工业工位**。
2. 选择 **零件上下料**，查看布局和流程，点击 **载入并运行**。
3. 观察机械臂接近圆柱、闭合双指、抬起、搬运、松开。抓取依靠物理接触与摩擦。
4. 在感知与数据区域查看物体高度、双指接触力、跟踪误差和放置结果。

成功的依据是运行结果与测量值。若失败，保留记录并查看观测、碰撞或规划失败原因。
不同机器的墙钟运行速度会不同，仿真时间和真实经过的时间是两种量。

四个工位可直接切换：

| 工位 | 当前实现 | 可以观察 |
|---|---|---|
| 零件上下料 | 圆柱从来料位搬到接收位 | 顶向接触抓取、定位与释放 |
| 来料分拣 | 三色物体分别送往接收位置 | 颜色观测与连续任务 |
| 成品码垛 | 三个箱件按层堆叠 | 放置顺序、堆叠稳定性 |
| 隔板避障转运 | 绕开静态挡板搬运物体 | 碰撞检查与路径规划 |

它们是桌面静态工位，未模拟移动传送带或机床加工。

## 3. 自由干预现场

| 操作 | 效果 |
|---|---|
| 按住积木拖动 | 在桌面移动物体；松手恢复动力学 |
| 按住物体时滚轮 / Shift 拖动 | 升降物体，绕过遮挡或堆叠 |
| 拖动机械臂连杆 | 施加有界弹簧外力；松手清除外力 |
| 拖动末端，Shift 升降 | 实际逆解与碰撞规划后执行目标 |
| 拖动障碍物 / 在场景面板编辑 | 改变现场布局；结构参数更改会重建场景 |
| 点击积木或颜色按钮 | 更换目标；已夹住其他物体时先完成其放置 |
| 右键拖动 / 普通滚轮 | 旋转视角 / 缩放 |
| 空格 / Esc | 暂停或继续 / 结束当前拖动与施力 |

自动任务会持续维护目标。移走已经放好的物体后，机械臂可以重新观察并搬回。
需要完全手动操作时选择 **转为自由操控**；选择 **交给机械臂** 恢复任务。
手动拖动物体属于位置约束，不是机械臂抓取力的证据；遇到几何阻挡会停止并高亮阻挡物。

## 4. 查看真实算法过程

顶部选择算法后即生效：控制器立即切换，逆解、规划和时标用于下一段运动。
切换后不需要再点“应用”。打开运算面板，拖动末端，查看残差曲线、关节增量、Jacobian 与末端变换。

想比较算法：进入 **对照** 区域，选择逆解、路径规划、轨迹或控制器，点击 **运行同场景对照**。
每一行都重新运行物理任务，失败也会保留。查看完成数、放置误差、跟踪 RMS 和非预期接触，点击 **导出 CSV** 保存结果。
不要在一次对照中同时改变模型、物体和目标；改变后应重新开始整组对照。

菜单 **工作区 → 算法实验室** 可查看搜索树、迭代和轨迹细节。
支持的方法与边界见 [使用指南](USER_GUIDE.md)。

## 5. 保存场景和实验

**场景**：在场景面板点 **采用画面摆放**，再到场景库命名保存或 **导出 JSON 文件**。
可以从零编辑，也可下载内置工位 JSON 再调整。完整说明见 [自定义场景](SCENES.md)。

**实验**：在记录区点 **保存当前运行**；底部 **导出本次数据** 获取原始 JSON。
场景文件保存初始配置，实验文件保存过程与结果，两者不能互相导入。
记录中的严格复算需要相同的源码、模型与运行环境；普通画面回放只是查看已保存帧。

桌面导出文件在 `Data/Exports`。实验目录可从 App“文件”菜单打开；默认位于 App 的数据目录，
如果自行接入了已有记录目录，则以所选目录为准。未保存的实验不会在关闭时自动归档。

## 6. 备份与升级

关闭 App 后备份整个 `Data` 和你另外选择的实验目录。分享场景时只发送导出的场景 JSON。
升级时把新包解压到新目录，再把旧 `Data` 复制过去；不要在两个 App 中同时使用同一个数据目录。
旧浏览器命名场景通过 JSON 导出 / 导入迁移，App 不读取浏览器个人资料。

遇到问题先看 [故障排查](TROUBLESHOOTING.md)。想修改代码见 [开发与构建](DEVELOPMENT.md)。
