# ADR 0002：提前提供本地网页几何预览

- 日期：2026-11-14
- 状态：根据用户本轮追加需求实施

## 背景

原任务卡 M0 不包含 GUI。用户进一步明确完整机器人工作台的产品目标，要求有可观看的机械臂画面、
运控库和可交互界面，并选择“本地网页工作台”。以用户最新需求为准，为当前版本增加可操作预览。

## 决定

- 浏览器直接运行无需构建的 HTML/CSS/ES module，Python 标准库提供本机服务。
- 原创六轴几何与 FK 只用于预览，明确显示未验证动力学、碰撞和 IK。
- 提供 Compact/Reach 两套几何尺寸，不借用厂商名称或暗示已验证多种工业机器人。
- 可操作的功能全部实现：模型切换、关节角、相机、播放、轨迹、曲线、姿态导出和后端测试实验。
- 运控算法与 MuJoCo 以“计划中”描述，不放置假装能执行的算法按钮或虚构评测结果。
- 不发布网站，所有文件与计算保留本机；前端不加载第三方远程素材。

## 后果

用户可以立刻评审交互方式。浏览器预览与 Python 后端暂时拥有不同的数据模型，不能混用实验结论。
M1 将统一受验证机器人描述并接入后端状态；预览模型不能直接认定为真实机器人资产。
此增量不意味着 M1/P0/P1 已实现，也不放宽论文生成代码的隔离要求。
