# ADR 0001：Core / Backend 边界

- 日期：2026-11-14
- 状态：M0 实施决定

## 背景

未来需要同时支持机械臂、移动机器人和浮动基座；提前绑定 MuJoCo/IK/GUI 会使接口失去可移植性。
本轮没有既有模型/算法源码可迁移。

## 决定

1. Core 只使用标准库，定义不可变数据、SI 单位、frame、哈希、错误和后端 Protocol。
2. 状态、参考、命令分开；qpos/qvel/ctrl 显式映射，接受 free joint 的 7/6 结构。
3. 不使用 NumPy 可写数组作为基础合同，当前使用 tuple 快照；未来适配器负责数值库转换。
4. Registry 外置，采用严格版本化 JSON 校验与能力匹配；不动态加载外部代码。
5. 先用确定性 FakeBackend 验证合同、CLI 和工件，物理引擎在 M1 实现。
6. 以内容标识稳定 run_id；记录观测与输入哈希，保证同环境重放可核查。

## 结果与代价

运行包零第三方依赖、可独立 wheel 安装。Core 可以在无机器人 SDK 的 CI 中测试。
schema 校验代码需要维护；复杂算法参数与大量数值数组将来可能需要增加可选依赖与适配层。
当前插件仅有注册元数据，协议尚不代表已经具备可运行算法。

## 迁移

这是首次实现，无旧 API。后续破坏性变更必须增加 ADR、版本变化和迁移测试。
